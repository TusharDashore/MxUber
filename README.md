# MxUber User App

A Flutter-based user application for a ride booking platform.

## Features

- User authentication
- Location access
- Google Maps integration
- Ride booking flow
- Firebase integration
- Real-time database support
- Push notifications
- Clean and responsive UI

## Tech Stack

- Flutter
- Dart
- Firebase Authentication
- Firebase Realtime Database
- Firebase Cloud Messaging
- Google Maps API

To run this project:

```bash
flutter pub get
flutter run
